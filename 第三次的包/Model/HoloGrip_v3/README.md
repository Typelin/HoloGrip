## 為什麼用 ratio < 1.35

我把每個事件的「標記手峰值 / 另一手峰值」算出來：

```
壓倒 >2.0        255 筆 (83.1%)
明顯 1.5-2.0      28 筆 ( 9.1%)
略勝 1.2-1.5       7 筆 ( 2.3%)
幾乎相同 1.0-1.2   9 筆 ( 2.9%)
標記手反而較弱      8 筆 ( 2.6%)
```

**92.2% 的事件手別是明確的**，只有 24 筆（7.8%）模糊，而且集中在 **10-20 秒那段**（37% 模糊）。
把門檻設在 1.35 可同時最大化店內 balanced accuracy 與跨場次 balanced accuracy。

## 誠實的成績

### 店內（8/12，分左右手，5-fold 時間區塊 GroupKFold，n=287）
```
acc 95.47%   balanced 94.65%   macroF1 94.55%
逐類召回：小鼓 97.1 / 高音Tom 84.8 / 中音Tom 85.3 /
          落地Tom 100 / Hi-Hat 100 / Crash 97.7 / Ride 97.6
```

### 跨場次（8/12 訓練 → 8/5 測試，同一人，n=247）
```
acc 87.85%   balanced 71.46%   macroF1 63.80%   左右跨側大錯 0/204
```

### 現場少量校準（模擬：每個 hand×鼓 只用 1 擊校準）
```
不校準       acc 87.85%   balanced 71.46%   macroF1 63.80%
1 擊校準     acc 93.73%   balanced 86.94%   macroF1 75.32%
             （20 次隨機重抽，acc 範圍 88.56% ~ 98.73%）
```

**這是本包最重要的結果**：現場只要花 30 秒、每個 hand×鼓 打一下，跨場次 balanced accuracy
就從 71% 拉到 87%。**建議現場流程務必保留這個校準步驟。**
