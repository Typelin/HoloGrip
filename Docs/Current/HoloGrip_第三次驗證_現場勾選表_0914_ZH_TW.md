# HoloGrip 第三次驗證｜現場勾選表

## 出發前

- [ ] 執行 `HoloGrip第三次驗證_出發前檢查.bat`，看到 `SOFTWARE READY`
- [ ] 兩隻手套、兩條主 USB 線、至少一條備用線
- [ ] 筆電充電器；關閉睡眠與 USB 省電
- [ ] 確認電子鼓可以保存「原始 MIDI 檔」
- [ ] 記下新歌 BPM（即使 MIDI 有 tempo 也記）
- [ ] 可選：手機錄影，畫面同時看到人與鼓組

## 到場後，正式驗證前

- [ ] 鼓組位置與第二次相同
- [ ] 演奏者站在同一歸零原點
- [ ] 開 `HoloGrip第三次驗證.bat`
- [ ] 選兩個不同 COM，左右手都出現
- [ ] 左右手都約 100 Hz
- [ ] 按「開始場次」；確認畫面顯示資料夾路徑
- [ ] 回固定原點，按「歸零」
- [ ] 按「5秒靜止預檢」；若 WARN，先處理硬體／重歸零，不進正式歌曲

## 七鼓慢打（不訓練）

每換一顆鼓，先按 GUI 上對應鼓名，再打 5–10 下：

- [ ] 小鼓
- [ ] 高音 Tom
- [ ] 中音 Tom
- [ ] 落地 Tom
- [ ] Hi-Hat
- [ ] Crash
- [ ] Ride

判讀：

- [ ] 有事件，但少數相鄰鼓混淆 → 記錄，可繼續
- [ ] 大量完全不合理鼓位 → 先查歸零／手套座標
- [ ] 常常完全沒有事件 → HitDetector 問題，不是先怪 MLP

## 正式新人 + 新歌

- [ ] 電子鼓「另開一個正式歌曲 MIDI 錄製」
- [ ] HoloGrip 按「正式歌曲開始」
- [ ] 完整演奏；途中不改模型、不改 threshold、不重訓
- [ ] 結束按「歌曲結束」
- [ ] 保存電子鼓 MIDI 原檔，不覆寫
- [ ] HoloGrip 按「停止場次」
- [ ] 確認場次資料夾有 `raw_100hz.csv`、`predictions.csv`、`markers.csv`、`session_summary.json`

## 當場出錯的處理順序

1. 先看左右手 Hz / COM / zero / gap。
2. 回固定原點檢查歸零；必要時停止這一輪、重新開始新場次。
3. 同一顆鼓重複慢打 5 下確認是否可重現。
4. 不要拿新人資料覆寫 0826 frozen model。
5. Raw CSV + MIDI 有保存，就還能回來把問題完整拆開。
