## 執行

Python3.12.10，從此目錄執行；模型是可信本機訓練的joblib／pickle，不能用此入口載入來路不明模型。

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python Program/world_stream_runtime_1019.py --raw "完整Raw.csv" --model Model/model.joblib --output "outputs/replay.csv" --stream
```

入口只有Raw、模型、輸出位置，不讀MIDI、不讀標記、不知道應該用哪隻手打哪顆鼓；答案產生後才由私有評分流程比對MIDI。已存在的預測CSV拒絕覆寫。會另外輸出同名manifest，故每次應使用全新的輸出檔名。不要將私人演奏輸出加入公開倉庫。

## Raw欄位契約

UTF-8／UTF-8 BOM CSV，一列一個手套封包，按接收順序排列；每手的song_time_ms不得倒退。合成測試資料由程式產生，沒有演奏者私人資料。

| 必要欄位 | 單位與用途 |
| --- | --- |
| hand | L或R；由裝置HAND_ID提供，選對應手模型 |
| song_time_ms | 錄製時間ms；打擊時間與輸出時間軸 |
| sensor_time_ms | 裝置時間ms；軌跡的物理取樣網格 |
| ax_g、ay_g、az_g | 感測器座標加速度g，含重力 |
| yaw_deg、pitch_deg、roll_deg | 原始姿態角度，世界座標換算使用ZYX旋轉 |
| cal_yaw_deg、cal_pitch_deg | 錄製時已完成的歸零角度；不重算 |

同手裝置時間須按時序遞增，資料品質與斷線處理由正式收集端負責。這個快照不是通用CSV轉換器；不能把其他欄位名稱直接更名卻不確認時鐘與姿態語意。

## 固定模型

- `clear_accel256sqrt`，6,667個擬合事件，10份歌曲／四鼓／單手補強錄製。
- 每手MLP256→128；固定生成417維、選219維，模型內含選欄與scaler。無GBDT、無背景類別、無拒絕類別。
- 外部偵測2.3g、rise0.75g、每手80ms冷卻／合併；峰前240ms～峰後80ms的已到達封包軌跡。
- 不新增開場小鼓或逐鼓校準，不用當天MIDI算參考姿態；不是現場重新訓練。
- 同手80ms內快速連打、低於門檻的真實輕擊仍有漏判風險。80ms上下文不是端到端實測延遲。

`Program/`保留八個歷史模組的檔名與原始位元組，以便比對驗證指紋；唯一推薦入口為`world_stream_runtime_1019.py`。相依舊模組中的舊模型入口、預設120ms或其他研究變體不代表本版使用它們，本版參數以固定bundle與manifest為準。

## 驗證與公開邊界

`manifest.json`記錄凍結模型與八個模組的SHA-256；`evidence/metrics.json`記錄評分總表，`evidence/verification.json`保留13份Raw-only驗證的去識別化指紋和檢查摘要。

公開測試驗證模型架構、訓練成員／前測不重疊、scaler列數、統計算式、檔案指紋、合成Raw逐包／批次一致，以及截斷未來封包的因果性。它**不能在沒有私有Raw／MIDI時重新計算真實命中率**。真實資料已在原工作區驗證，公開JSON是摘要證據，不是公開測試集。

未發布原始CSV、MIDI、影片、逐事件標記、完整研究訓練程式與私人路徑。這是固定推論快照，**不是可從零重訓的完整資料集發布**。模型權重本身屬研究產出，不應當成匿名化資料集或差分隱私保證。
