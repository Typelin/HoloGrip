# HoloGrip 第四、五、六次資料：跨錄製前測里程碑

## 階段成果

版本日期：2026-10-19。凍結候選：`clear_accel256sqrt`。

本階段完成外部打擊偵測與神經網路鼓種分類的完整 Raw 重播。使用第四、五、六次歌曲、四鼓強化與單手補強訓練；另外三份未參與模型擬合或 scaler 的前測，命中率分別為 **87.1%、91.3%、90.7%**，最低 **87.1%**，合計 **529／594＝89.1%**。

可對外使用的表述：

> 使用第四至六次蒐集資料訓練，完成三份跨錄製前測的完整 Raw 重播，命中率皆達87%以上；模型與推論流程已凍結，等待下一次現場驗證。

上述前測曾反覆用於特徵與模型選版，且訓練包含相同場次的其他錄製，因此屬於「跨錄製開發測試」，**不是整天留出的跨場次盲測，也不是未見鼓手的成功率**。不能延伸成每隻手、每顆鼓都有87%以上機率。

## 模型與因果推論流程

`100 Hz Raw → 外部打擊偵測 → 已到達封包的軌跡特徵 → 左／右手MLP → 保存全部預測 → 最後才比MIDI`

打擊與鼓種各司其職。外部偵測使用合成加速度門檻2.3g、上升量0.75g、每手80ms冷卻與合併、1個取樣點確認及峰後80ms上下文；此階段未改動偵測器。分類器不判斷有沒有打，也沒有「拒絕／不確定」輸出類別。

分類模型為左右手各一個MLP，隱藏層256→128、ReLU、Adam、L2 alpha=0.3、每手／鼓反平方根樣本數加權；不是GBDT或樹模型投票。類別為小鼓、高音Tom、中音Tom、落地Tom、Hi-Hat、Crash、Ride，HAND_ID決定使用哪一手的網路。

軌跡以感測器時間取峰前240ms至峰後80ms、10ms網格。產生417維，pipeline固定選219維：世界座標線性加速度及幅度波形、短窗積分形狀與分段統計，移除逐點相對旋轉／角速度波形。世界轉換仍需要原始姿態，分段統計仍保留轉動統計，不能稱為完全不使用角度。短窗積分是辨識特徵，不是可靠的手部位置追蹤。

推論只收Raw與固定模型，不接受MIDI、手別答案、鼓種答案或預期演奏順序，不從歌曲標記算小鼓基準，不新增開場逐鼓校準。它沿用Raw內已錄下的歸零欄位，不事後重估歸零。每次特徵只讀到該次輸出時已收到的封包；峰後80ms是演算法上下文等待，不是實體端到端延遲保證。

重疊軌跡不會讓模型每10ms重複輸出打擊：先由外部偵測器產生事件，再對事件分類。80ms冷卻仍可能合併同手急速連打，低於門檻的真實輕擊也可能漏判，並未宣稱已全部解決。

- 既有獨立驗證：13個Raw-only程序；三份前測逐包169,120列、850筆完整輸出，與批次結果一致。850是全段輸出數，不是評分範圍內的594個MIDI分母。
- 39個截斷未來封包的特徵檢查通過；6,667個擬合成員、兩手scaler列數及前測不重疊已核對。
- 四份正常力度評估均獨立逐包重播，同一模型與完整輸出未改；原始來源與第七次包指紋未變。
- GitHub快照提供模型、八個原樣推論模組、去識別化統計、來源／輸出摘要指紋，以及可在無私人資料下執行的模型契約、合成串流與因果性測試。
- 公開快照不含演奏Raw、MIDI、影片、私人路徑或逐事件演奏資料；公開測試能驗證模型與流程契約，不能在缺少私人真值時獨立重算上述實驗命中率，也不宣稱能從零重訓重現。

## 限制與下一階段驗收

1. 凍結本版模型與偵測參數後，使用下一次全新錄製做前瞻驗收；不得以新考卷調參後仍稱同一份盲測。
2. 保持現場鼓面歸零流程，不新增小鼓／逐鼓教學。測試前預先固定配對容忍、有效事件範圍、弱擊政策，報告命中、漏判、錯鼓、多報及各手／鼓樣本數。
3. 另外驗證GUI／COM輸入、封包品質、完整Raw保存、急速連打與端到端延遲。此里程碑只驗證軟體重播，沒有實體打鼓驗收。
4. 仍須處理正常力度的漏判、Crash弱擊／疑似重觸發及歌曲2多報，不能以刪掉困難答案宣稱全部90%以上。
5. 新鼓手、新場地與完全未見場次的泛化尚未證明；目前資料量與評分不能支持每手每鼓90%以上保證。

本快照**沒有更新10/20第七次包的GUI、BAT或現場模型路由**；不能只把新模型覆蓋到舊維度模型位置。公開倉庫原有UDP入口亦非此快照的推論入口。
