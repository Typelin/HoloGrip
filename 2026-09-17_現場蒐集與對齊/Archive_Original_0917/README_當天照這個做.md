# HoloGrip 2026-09-17 現場蒐集與對齊

## 器材清單

### 流音系準備

- 電子鼓、電子鼓電源線。
- 可錄製並匯出原始 MIDI 的電腦與充電器。
- 電子鼓模組連接電腦所需的 USB／MIDI 資料線。
- iPhone、腳架、足夠儲存空間與充電器／行動電源。
- 本次歌曲檔案與 BPM；演奏結束後立即匯出 `.mid` 或 `.midi`。

### 電子系準備

- 左手套、右手套。
- **兩條** 3 米 Type-C 資料線，每隻手套一條；另帶一條備用線較安全。
- HoloGrip 電腦與充電器。
- USB 孔不足時使用有供電 USB Hub。
- 延長線／排插。
- 本資料夾完整工作包。

## 出發前

1. 左右手套都插上電腦。
2. 執行 `00_出發前與現場檢查_ZH_TW.bat`。
3. 必須看到兩個不同 COM。
4. 手套通常不需要重燒。若確實需要，左手只使用 `Firmware/Gloves_Left_L/Gloves_Left_L.ino`，右手只使用 `Firmware/Gloves_Right_R/Gloves_Right_R.ino`；不可把同一份韌體燒入兩手。

## 現場完整順序

1. 執行 `00_出發前與現場檢查_ZH_TW.bat`，確認兩個不同 COM。
2. 執行 `02_LIVE_MODEL.bat`，先測試上次模型的現場效果。
3. 測試完成後**關閉即時模型程式**，釋放兩個 COM。
4. 執行 `01_COLLECT_RAW_100HZ.bat`，收集本次原始 CSV。
5. 請流音系匯出同一次演奏的原始 MIDI，放入 `Data/MIDI/`。
6. 執行 `03_ALIGN_MIDI_CSV.bat`，先檢查 MIDI，再做 MIDI＋CSV 對齊。
7. 在產生的 HTML 檢查開頭、中段、結尾與異常事件；確認後才離場。

建議正式歌曲前先錄一小段同步測試：七個鼓各慢打數次，鼓點之間留明顯間隔。CSV、MIDI、影片必須記錄**同一次演奏**。

## 正式蒐集 Raw CSV

1. 執行 `01_COLLECT_RAW_100HZ.bat`。
2. 選兩個不同 COM，按「連接 COM」。
3. 確認左右手都有資料。
4. 雙手在固定原點按「雙手統一歸零」。
5. 確認模式為「原始 100 Hz」。
6. 輸入場次 ID，例如 `S20260917_P02_song01`。
7. 按「開始歌曲收集」後才開始演奏。
8. 演奏結束按「停止並存檔」。
9. CSV 自動放在 `Data/CSV/`。

## 取得 MIDI 後直接對齊

1. 把流音系提供的 `.mid` 或 `.midi` 放入 `Data/MIDI/`。
2. 執行 `03_ALIGN_MIDI_CSV.bat`。
3. 工具會自動選取 `Data/CSV/` 與 `Data/MIDI/` 中最新的檔案，請確認檔名。
4. 確認 BPM，窗口先使用 ±80 ms。
5. 只有 MIDI 時，按「只有 MIDI：先檢查 MIDI」。頁面會列出事件數、各鼓點數量、最小間隔、20 ms 內重複與過度密集區。
6. CSV 與 MIDI 都有時，按「尋找 MIDI → CSV 對齊」。工具會搜尋候選時間偏移，再產生檢查頁。
7. 完成後會自動開啟已嵌入本次資料的檢查 HTML。
8. 在 HTML 依序檢查第一個事件、中段、最後一個事件，再看「下一個異常」。MIDI 點應落在合理的左右手活動尖峰附近。
9. 結果全部放在 `Data/Alignment/`。

若 GUI 沒自動帶入檔案，可把 CSV 與 MIDI 拖進視窗，或按「瀏覽」手動選取。不需要自己打開空白 HTML。

`Frontend/` 裡的 HTML 是空白模板，不含舊資料。不要用它直接檢查；請一律從 `03_ALIGN_MIDI_CSV.bat` 產生本次檢查頁。

## 即時模型驗證

需要展示手套即時判斷哪一個鼓時，另外執行 `02_LIVE_MODEL.bat`。

資料蒐集與即時模型驗證都會獨占 COM，兩個程式不能同時開啟。
