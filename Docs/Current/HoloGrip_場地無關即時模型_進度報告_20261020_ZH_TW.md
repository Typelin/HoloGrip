# HoloGrip 進度報告：場地無關即時模型上線第七次現場包（2026-10-20）

## 一、目前狀態（一句話）

第七次現場包 `第七次的包_暫定2026-10-20` 的 `1_測前次.bat` 已換成**場地無關、逐下即時判斷**的七鼓模型。三份沒進訓練的前測命中率為 72.1%／76.2%／80.0%。軟體測試全部通過，2026-10-20 早上已在電腦前用實體手套試打，反應符合現場預期。

## 二、目標與兩個硬性條件

辨識兩隻 IMU 手套（WitMotion JY＋ESP32，100 Hz，COM4＝右手、COM5＝左手）每一下打在哪顆鼓（小鼓、高音 Tom、中音 Tom、落地 Tom、Hi-Hat、Crash、Ride）。電子鼓 MIDI 只當答案。

1. **必須馬上看到打擊結果**：打一下就出一個結果，不能整場錄完才判。
2. **必須不受場地限制**：換場地、換面向都要能用，不能記鼓房方位。

## 三、考試標準（使用者規定，所有成績都照這個算）

1. 前測（第四、五、六次）**一律不進訓練**，當成三份陌生考卷。
2. 照時間軸即時考：每一下只能用到「這一下＋打擊後最多 80 ms」的資料。不能用未來的打擊、整份錄音的統計，也不能讀 MIDI（MIDI 只在交卷後評分）。
3. 不准用地磁或絕對方位當特徵。把所有 Yaw 加上一個常數（模擬換場地），判斷必須完全不變。
4. 運算用 GPU（RTX 5090 Laptop 24 GB）。
5. 回報時，「有參與訓練的回代成績」和「陌生前測成績」分開寫，開發時挑選過的成績不能說成盲測。

## 五、新模型

### 偵測
外部打擊偵測器（與舊版相同），只改門檻：2.1 g、上升 0.75 g、80 ms 防重複、峰值後 80 ms 才放出。

### 特徵（每一下 104 維，只看這一下）
- **軌跡統計 83 維**：取打擊前 240 ms 到打擊後 80 ms，把加速度、角速度轉到「打擊瞬間那隻手自己的朝向」，所以換場地方向會完全抵消。
- **相對鼓面歸零的旋轉 21 維**：在 −120、−80、−40、−20、0、+20、+40 ms 七個時間點，計算手部姿態相對開錄前鼓面歸零姿態的旋轉（旋轉矩陣 Hd·R(t)·A⁻¹·Hd⁻¹）。這個算法跟場地方向無關，也能抵消手套戴歪的影響。

### 分類器
- 左右手各一組，每組 6 個委員一起投票。訓練時把歸零角度隨機偏移 ±10° 或 ±15°，模擬每次歸零手勢不同，每種偏移各 3 組種子。
- 每個委員＝XGBoost（決策樹）＋MLP（512-256-128 神經網路），機率平均。
- 用 GPU 訓練；現場用 CPU 判斷，每下約 12 ms。

### 訓練資料
第四、五、六次的歌曲、四鼓強化、清晰的單手補強，共 6,667 下（左手 3,618、右手 3,049）。**三份前測沒有進訓練。**

### 成績的意義與限制
- 十段基礎資料**有參與訓練**，是回代成績，只證明模型學得到、流程沒壞。
- 前測沒進訓練，但特徵組合、歸零偏移、委員數是看著這三份的成績挑的，所以是**開發成績，不是盲測**。
- 前測和部分訓練資料是同一天錄的（例如第四次前測與第四次四鼓強化），是「陌生場次」，不是「陌生的一天」。
- 前測的錯幾乎都是判成相鄰的鼓，很少漏抓。主因是每次鼓面歸零的手勢不一致。
- 第四、五次前測沒有逐筆手別答案，只比時間和鼓種。
- 舊地磁模型在原鼓房方向是 87.1／91.3／90.7%，但換場地會失效，所以不採用。
- **10/20 現場新錄的前測，才是第一次真正的盲測。**

## 七、驗證

- **即時＝批次**：把原始錄音一筆一筆餵進第七次包的即時程式，和一次算完的結果比對。三份前測加兩段訓練錄音，每一下的時間、手別、鼓種完全相同，分數差小於 1e-7；前測成績重現 72.1／76.2／80.0%。
- **換方向不變**：三份前測所有 Yaw 加 90°、−137°，判斷完全相同。
- **出結果時間**：峰值後通常 80～94 ms 放出，最多 110 ms；判斷運算中位數約 12 ms，最慢約 19 ms（第 99 百分位）。
- **套件測試**：16 項全部通過，原生 GUI 測試、`00_CHECK`、`1_測前次` 啟動測試也都通過。
- **實機**：10/20 早上在電腦前接實體手套試打，反應符合預期（歸零後還需要用滑鼠按開始）。

## 九、現場注意事項（10/20）

1. 使用 `第七次的包_暫定2026-10-20`，不要用備份資料夾。
2. **每次用同一個方式歸零**：放在小鼓鼓面上、同樣的手勢。歸零是位置判斷的基準。
3. 先開 `00_CHECK.bat` 確認軟體 PASS，再開 `1_測前次.bat` 確認 COM4／COM5 與左右手。
4. 前測照常同步錄 MIDI，錄完用 `3_檢查這次MIDI`、`4_對齊MIDI與CSV` 檢查。這份前測要當真正的盲測，不能放進訓練。
