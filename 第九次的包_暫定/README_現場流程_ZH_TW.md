## 跟第八次包的差別
- 模型：第 4～8 次資料訓練（19,358 下；第 8 次＝10/27 的單手補強、四鼓、歌曲）。前測一律不進訓練。
- 雙模型：3 個用原始資料訓練、3 個用「每段錄音先對齊到共同鼓位」的資料訓練，加權平均（原始 0.4、對齊 0.6）。
  - 對齊：每段錄音用它自己的答案，把整段的鼓位平移到共同座標。原因：每段歸零後「小鼓相對歸零的左右角度」都不一樣（10/27 左手 +2°～+67°、右手 −13°～−56°），手摸鼓面只固定了位置，沒固定手臂指的方向。
- 逐鼓位置校正：只用分數 ≥ 0.8 的打擊估這次的偏移（原本 0.7）。
- 自動錨點：每隻手開頭 5 下姿勢都在 8° 內，而且模型都認為最像小鼓 → 當小鼓錨點立刻校正；不是小鼓但模型每下都判同一顆鼓（平均分數 ≥ 0.7，例如開頭打 Hi-Hat）→ 用那顆鼓當錨點；都不像就不強迫，等 20 下有把握的打擊再校正。鼓手不先打小鼓也可以。
- 位置先驗：每一下的手部角度離某顆鼓的訓練位置越遠，那顆鼓的分數越低（σ 12°、權重 0.5；左右角度以圓周計算）。修正「位置明明在 Ride、卻因揮擊動作被判成 Tom」這類錯誤。
- 姿勢連續（前兩名）、打擊判斷（1.5 g＋學習判斷）、不用地磁：與第八次相同（方向加 90° 判斷完全相同）。

- 全部訓練：模型看過同一天的其他錄音（不含前測），而且參數是看這五場前測挑的 → 開發分數，偏樂觀。
- 留一天：被考的那一天完全沒進訓練，最接近下一次現場的表現（預估下次前測約 85～88%）。
- 重複觸發：電子鼓同一下送出兩個同鼓音符（相隔 11～130 ms），手套只有一下 → 算一下（只看手套峰值，左右手各一下的快速連打會保留）。
- 還沒到 85% 的格子（全部訓練）：第 6 次左手中音 5/10（那份前測左手中音與落地的姿勢幾乎重疊，只差 2°，個案）。
- 「沒把握不回答」評估：留一天門檻 0.6 只把回答的正確率從 89.4% 提到 91.9%，卻有 16% 不回答（跨天的錯常是很有把握地整段判成隔壁鼓），所以預設不開。

## 現場操作（不變）
`00_CHECK.bat` → `1_測前次.bat`（連接雙手 → 鼓面歸零 → 開始新測試）→ `2_蒐集這次.bat` → `3_檢查這次MIDI.bat`。
- 每次都在小鼓鼓面上用同樣的姿勢歸零。
- 開始後先打幾下小鼓會更快校正；不打也可以。
- 如果中途移動鼓位：重新歸零，並重開一次測試。

## 收集建議
- 前測（盲測，不進訓練）：每隻手先打小鼓（左 10、右 10），再從小鼓開始每鼓左 20、右 20。
- 單手補強：雙手 Hi-Hat（10/27 沒錄）、左手 Ride、左手中音 Tom。
- 打 Tom 時留意線或鼓棒碰到小鼓：會產生假小鼓（力度 3～10），標記時已自動排除。
