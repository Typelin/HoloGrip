# KEEPALIVE｜密集事件軌與選取片段播放同步

## 本次目標

修正主頁局部時間圖中，上方彩色事件長方形與下方 MIDI／CSV 折線視覺移動速度不同的問題；同時讓「播放目前選取 MIDI 片段」確實播放選取事件前後的完整採樣窗口。

## 已完成

- 完整播放速度預設改為 `1x`，不再由 HTML 將 `12x` 預先選取。
- 新增共用 `localViewport()`，統一局部圖的 `min`、`max`、寬度與時間到 X 座標換算。
- 下方 CSV 折線與 MIDI 點使用共用局部視窗。
- 上方事件判定長方形改用同一局部視窗；原本密集層使用不同 `max` 公式，造成中心相同但移動尺度不同。
- 密集長方形改為固定 14px 寬度，避免同群組 MIDI 筆數造成邊緣移動的速度錯覺；群組筆數保留在 SVG `title` 中。
- 新增事件判定軌的綠色時間游標，與下方中央游標同一時間位置。
- 播放片段時固定綠色窗口左／右虛線，讓目前時間游標由左向右穿越固定範圍；事件導覽時間軸也同步固定播放範圍。
- 將「目前選取 MIDI」與「播放時間游標」分離；片段播放不再用鄰近事件覆寫選取索引，結束後恢復原選取點，重複按鈕會重播同一窗口。
- 「播放目前片段」現在直接使用畫面綠色採樣窗口：
  - 開始：綠色左虛線，也就是 `目前時間 − 採樣窗口半徑`
  - 結束：綠色右虛線，也就是 `目前時間 ＋ 採樣窗口半徑`
  - MIDI／CSV 時間游標由左向右掃過，中心事件在中點穿過中央游標。
