# TimingRobustEnsemble

由 2026-09-19 的自動化稽核產生，**尚未接進任何現場 GUI**。

## 與現行 TimingRobustAug20 的差別

| | TimingRobustAug20（現行） | TimingRobustEnsemble（本包） |
|---|---|---|
| 模型 | 單一 MLP(64,32), seed=42 | 12 個 seed 的 MLP(64,32) 機率平均 |
| 訓練事件 | 307 | 296（剔除 11 筆可疑手別） |
| 特徵 | vnext_core 31 維 | 相同 |
| 時間增強 | -20/0/+20 ms | 相同 |

## 為什麼要換

1. **現行模型的 95.14% 是 60 個隨機種子中的最大值。**
   同一份資料、同一個配方，不同 seed 的跨場次結果分佈為
   mean 87.32% / sd 3.61 / min 77.33% / max 95.14%。
   單一 seed 的結果不可重現。

2. **集成消除種子樂透。** 12 個 seed 機率平均後，跨場次穩定在 87.85%，
   不再依賴運氣。

3. **剔除可疑標記可提升店內成績。** 判準：標記手的 IMU 峰值 < 另一手的峰值
   （代表該擊打實際是另一手打的，或是一次擊打被算成兩次）。

## 重要警告

- 8/5 測試集是**自動篩過的**（只留單手、高信心、峰值 ≥1.0 g），
  且 **Hi-Hat 佔 57.5%**、Crash 只有 8 筆。這個數字不能當真鼓實戰的保證。
- **跨人（P02）從未驗證。**
- 這包**沒有接進** `field_v2_timing_robust_zero_shot.py` 或任何現場 GUI。
  要用的話必須先改 GUI 的模型載入路徑，並實測。
- 模型輸入必須是**真鼓擊打**。家裡空揮的 yaw 離散度是訓練集的 7.9 倍，
  本來就不在分佈內，測不出東西。
